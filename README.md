## О проекте

**RuRestore** — это открытый, бескомпромиссно быстрый и ориентированный на приватность нативный клиент для российского магазина приложений **RuStore**.

Официальное приложение RuStore от VK со временем превратилось в перегруженный гибридный комбайн: фоновые службы телеметрии, рекламные и аналитические SDK, тяжелые веб-контейнеры (WebView), фоновые push-демоны и настойчивое навязывание авторизации через VK ID. 

**RuRestore возвращает пользователю контроль и легкость:**
* **Никаких аккаунтов (Zero-Account)**: просмотр каталога, скриншотов, отзывов и загрузка любых APK доступны без единого клика на вход в VK ID.
* **100% открытый код и приватность**: полное отсутствие трекеров (0 трекеров по Exodus Privacy). Никакого сбора идентификаторов устройств, аналитики или передачи метаданных третьим лицам.
* **Кристально чистый нативный UI**: интерфейс написан с нуля на **Jetpack Compose** и **Material Design 3**, обеспечивая бескомпромиссные 60 / 120 FPS даже на слабых устройствах.

## Ключевые технологические возможности

### ⚡ Интеллектуальный сессионный кэш (Anti-Flicker)
В отличие от официального приложения, витрины RuRestore («Приложения», «Игры», «Категории») фиксируют полученный срез данных на время сессии:
* При переключении между вкладками, открытии карточек и возврате назад экраны **не перезапрашивают данные заново** и не мерцают.
* Обновление каталога происходит исключительно тогда, когда этого хочет пользователь — с помощью жеста **Pull-to-Refresh** («крутилка») сверху вниз с плавной анимацией Material 3 или при полном перезапуске приложения.

### 🛡️ Устранение гонок потоков установщика (Race Condition Free)
Специальный модуль контроля жизненного цикла `PackageInstaller` отслеживает реальный статус системной сессии установки:
* Полностью устранена проблема ложных баннеров *«Ошибка установки»*, возникавших ранее при задержке отправки broadcast-сообщений пакетным менеджером Android.
* Приложение корректно рапортует об успешной инсталляции и сразу переводит кнопку в статус «Открыть».

### 🇷🇺 Встроенный доверенный стек сертификатов Минцифры РФ
В сетевой стек (OkHttp3 / Conscrypt) интегрированы корневой и подчиненный сертификаты Национального удостоверяющего центра (НУЦ Минцифры России):
* Все защищенные эндпоинты RuStore (BackAPI, CDN скачивания APK, витрины) открываются стабильно и безопасно.
* Пользователю **не требуется** вручную устанавливать российские сертификаты в системное хранилище Android.

### 🎨 Material You & Адаптивный Gemini SVG
* Дизайн выполнен по спецификации **Material Design 3**: динамическая адаптация под цвета обоев (Monet на Android 12+), светлая, темная и ультра-черная (AMOLED) темы.
* Фирменная векторная адаптивная и монохромная иконка в каноническом стиле Gemini SVG идеально интегрируется в рабочий стол любого современного лаунчера.

### 🔗 Умная работа со ссылками
* **Поделиться**: генерирует официальную ссылку на веб-витрину RuStore: `https://www.rustore.ru/catalog/app/{packageName}`.
* **Открыть в магазине**: формирует нативный диплинк протокола RuStore `rustore://apps/details?packageName=...` (если установлен официальный клиент) с плавным перенаправлением в веб-каталог при его отсутствии.

### 🔍 Встроенный аудит безопасности (Exodus Privacy)
В карточке каждого приложения наглядно отображается список встроенных в него трекеров и запрашиваемых разрешений прямо перед установкой. Вы заранее знаете, насколько безопасно устанавливаемое приложение.

## Универсальный бинарный пакет (Fat APK)

Релизный APK `RuRestore.apk` является полностью универсальным (Fat APK) и не требует скачивания раздельных сплит-пакетов под каждую архитектуру:

```text
native-code: 'arm64-v8a' 'armeabi-v7a' 'x86' 'x86_64'
minSdkVersion: 23 (Android 6.0 Marshmallow и новее)
targetSdkVersion: 37 (Android 16 / 17 Preview)
```

Он оптимизирован и протестирован на:
- Современных смартфонах и планшетах (64-битный ARM `arm64-v8a`).
- Старых бюджетных устройствах (32-битный ARM `armeabi-v7a`).
- Эмуляторах и ПК-окружениях (`x86` и `x86_64`: Waydroid под Linux, Windows Subsystem for Android, Android Studio Emulator, BlueStacks).
- Чистых AOSP и кастомных прошивках без Google-сервисов (GrapheneOS, CalyxOS, LineageOS, /e/OS).

## Быстрая установка

Готовый скомпилированный APK (9.1 МБ) доступен на странице [Releases](https://github.com/Milordick/RuRestore/releases/latest) или в корне репозитория (`RuRestore.apk`).

### Установка через ADB

```bash
# Установка APK на подключенное устройство
adb install -r RuRestore.apk

# Быстрый запуск приложения
adb shell monkey -p com.coshick.rurst -c android.intent.category.LAUNCHER 1
```

## Сборка из исходных кодов

Для сборки проекта необходим **JDK 17+** и Android SDK (API 35–37):

```bash
# Клонирование репозитория
git clone https://github.com/Milordick/RuRestore.git
cd RuRestore/aurora_store

# Сборка отладочной версии (Debug)
./gradlew assembleVanillaDebug

# Сборка ультра-оптимизированного релиза (R8, ProGuard, 9.1 МБ)
./gradlew assembleVanillaRelease
```

Собранный релизный файл формируется по пути:
`app/build/outputs/apk/vanilla/release/app-vanilla-release.apk`
