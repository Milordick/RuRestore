**RuRestore** — это автономный, высокопроизводительный клиент для каталога приложений **RuStore**, разработанный на базе современного нативного стека Android (Kotlin 2.x, Jetpack Compose, Material Design 3, Coroutines, OkHttp3).

Приложение позволяет полноценно искать, просматривать, скачивать, обновлять и устанавливать приложения из официального каталога RuStore без навязчивых трекеров, рекламы, фоновой телеметрии, Google Play Services и без обязательной авторизации в VK ID.

---

## Быстрая установка

Готовый скомпилированный APK доступен в каталоге проекта (`RuRestore.apk`) и во вкладке **Releases**.

### Установка через ADB

Подключите Android-устройство с включенной отладкой по USB и выполните команду:

```bash
adb install -r RuRestore.apk
```

Для быстрого запуска приложения на устройстве:

```bash
adb shell monkey -p com.coshick.rurst -c android.intent.category.LAUNCHER 1
```

## Что делает RuRestore и ключевые преимущества

Официальный клиент RuStore перегружен лишними компонентами, аналитикой, гибридным WebView-кодом и требует привязки к сервисам VK. **RuRestore** решает все эти проблемы, предоставляя чистый, открытый и молниеносный инструмент:

1. **Zero-Account / Полная анонимность**:
   - Весь каталог, скриншоты, отзывы, поиск и загрузка APK доступны прямо из коробки без авторизации через VK ID. Никаких привязок телефонных номеров, сбора профилей или передачи персональных данных.

2. **100% нативный Jetpack Compose (Без WebView)**:
   - Полный отказ от веб-оберток в пользу современного декларативного UI-фреймворка Jetpack Compose с аппаратным ускорением и плавной частотой кадров (60 / 120 FPS).

3. **Интеллектуальный сессионный кэш (Anti-Flicker)**:
   - Главные ленты («Приложения», «Игры», «Категории») больше не перезапрашивают данные из сети и не мерцают при переходах между вкладками, открытии карточек и возврате назад.
   - Данные витрины зафиксированы на протяжении всей сессии и обновляются строго по жесту **Pull-to-Refresh** («крутилка») сверху вниз с плавной Material 3 индикацией либо при холодном перезапуске.

4. **Устранение гонки потоков установщика (Race Condition Fix)**:
   - Встроенный интеллектуальный механизм контроля сессий `PackageInstaller` исключает появление ложных ошибок *«Ошибка установки»* после успешного завершения записи пакета системой.

5. **Глубокая интеграция ссылок и шеринг (Deep Linking)**:
   - Функция «Поделиться» генерирует официальные веб-ссылки `https://www.rustore.ru/catalog/app/{packageName}`.
   - Кнопка перехода в магазин нативно открывает глубокую ссылку протокола `rustore://apps/details?packageName={packageName}`, если на устройстве установлен официальный клиент, либо перенаправляет в браузер.

6. **Встроенные SSL-сертификаты Минцифры РФ**:
   - В сетевой стек интегрированы корневые и промежуточные сертификаты Национального удостоверяющего центра (НУЦ Минцифры России), что гарантирует бесперебойную загрузку пакетов и связь с API без ошибок SSL handshake.

7. **Кастомный геометрический брендинг**:
   - Уникальный адаптивный векторный знак, полная совместимость с динамической темой **Monet (Material You)**, монохромными иконками и темным режимом.

## Интерфейс (Google Material You M3)

Интерфейс спроектирован по строгим канонам **Material Design 3**:

- **Главный экран (Витрина)**:
  - Секции «Рекомендуем», «Лучшее», «Категории», «Всё от VK», «На каждый день», «Нейросети».
  - Горизонтальные карусели с баннерами и карточками приложений.
  - Поддержка обновления списка свайпом сверху вниз (`PullToRefreshBox`).
- **Страница приложения**:
  - Полное описание, категория, версия, размер, целевой SDK, дата релиза и обновления.
  - Полноразмерная карусель скриншотов с зумом.
  - Раздел оценок и отзывов с расчетом рейтинга и гистограммой распределения голосов (1–5 звезд).
  - Быстрый переход к другим приложениям того же разработчика по клику на имя автора (`pub:DeveloperName`).
  - Просмотр трекеров через встроенную базу **Exodus Privacy**.
- **Менеджер загрузок и обновлений**:
  - Пакетная установка и фоновое скачивание с отображением точной скорости (МБ/с) и оставшегося объема.
  - Обновление установленных приложений в один клик.

## Сборка из исходников

Для сборки проекта требуется **JDK 17+** и настроенный **Android SDK (API 35–37)**.

```bash
# Клонирование репозитория
git clone https://github.com/Milordick/RuRestore.git
cd RuRestore/aurora_store

# Сборка отладочного APK (Debug)
./gradlew assembleVanillaDebug

# Сборка оптимизированного релизного APK (Release)
./gradlew assembleVanillaRelease
```

Собранный файл будет находиться по пути:
`app/build/outputs/apk/vanilla/debug/app-vanilla-debug.apk`
